# Sources and their limits

Reviewed 2026-09-13. Original Skill text and code; linked sources are not licenses
to copy third-party material. Platform behavior may change.

- [Repository search](https://docs.github.com/en/search-github/searching-on-github/searching-for-repositories): default fields and qualifiers, not ranking weights or search volume.
- [Topics](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/classifying-your-repository-with-topics): format and purpose, not guaranteed ranking boosts.
- [Discovery](https://docs.github.com/en/get-started/exploring-projects-on-github/finding-ways-to-contribute-to-open-source-on-github): multiple discovery routes, not their traffic share.
- [Social preview](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview): separate repository setting; committing an image alone does not apply it.
- [Traffic](https://docs.github.com/en/repositories/viewing-activity-and-data-for-your-repository/viewing-traffic-to-a-repository): recent window and referrer limitations.
- [Traffic API](https://docs.github.com/en/rest/metrics/traffic): permissions and available metrics, not full attribution.
- [Acceptable use](https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies): prohibits spam/inauthentic activity and rank abuse.
- [Agent Skills specification](https://agentskills.io/specification): file format and progressive resources, not runtime guarantees.
- [Skills CLI](https://github.com/vercel-labs/skills): documented installation and search interfaces, not proof of this package's installation.
- [Codex skills](https://developers.openai.com/codex/skills/): client discovery documentation, checked via the official documentation redirect.
- [Claude Code skills](https://code.claude.com/docs/en/skills): client discovery documentation, not a local execution test.
- [GitHub CLI create](https://cli.github.com/manual/gh_repo_create), [edit](https://cli.github.com/manual/gh_repo_edit), [view](https://cli.github.com/manual/gh_repo_view): publication mechanics requiring authorization.

Comparative sources are in [research.md](research.md). The initial package has no
personal battle-tested growth story, no external user dataset and no viral proof.
