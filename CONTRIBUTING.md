# Contributing

Prefer a small reproducible improvement over another vague growth promise.

For a bug include package/Python/OS version, a sanitized fixture, expected versus
actual outcome, and exact commands. Run `python -m unittest discover -s tests -v`.
Do not include credentials, user prompts, private analytics or private source.

For a proposed lesson use the learning template within the skill. Cite current
primary sources or consented observations. Separate correlation from causation.
No automatic directory submissions, promotional PRs, paid stars or hidden tracking.

Changing publication boundaries, execution behavior or dependencies needs explicit
maintainer review. Do not relax a failing check just to pass CI. Host permissions
always override a skill's instructions.
